# Design records

These are the design documents and implementation plans that drove the code, kept as
written. They are historical: a plan may describe a command that was later renamed or
never built, and the code is the authority on current behavior.

Issue and pull-request numbers in these files (`#NNN`) refer to the private development
tracker, which was not published with the repository. The commits are the durable
record; see [How this project is built](../ai-development.md).
