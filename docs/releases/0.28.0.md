# ia 0.28.0

Released from tag `v0.28.0`. Covers everything merged after `v0.27.0`:
PRs #168, #172, #173, #174 and #176. `ia-core` and `ia-cli` are both 0.28.0.
The minor bump is because the release adds a flag and an installer and
changes behavior that scripts and library callers can see: JSONL and
spreadsheet input that was accepted is now refused, and a 429 from the Tasks
API is now `IaError::RateLimited`. They are listed below.

## New

- **`ia upload --size-hint <BYTES>` sets `x-archive-size-hint`**, as the
  Python tool does (#176). The value is sent as given, in place of the
  computed total. It is refused with `--no-size-hint` and with a `--header`
  that sets the same header. A `--header x-archive-size-hint:N` alone now
  replaces the computed value instead of being sent twice. With
  `--dashboard` and three or more files, the last file now carries the hint
  when no earlier file uploaded. Not verified against live IA-S3.
- **`install.sh`**, a one-line installer for macOS and Linux (#173):
  `curl -fsSL https://raw.githubusercontent.com/internetarchivecanada/ia/main/install.sh | sh`.
  It checks the download against `SHA256SUMS`, installs `ia-cli` to `~/bin`
  without sudo, and runs the binary before replacing an existing one.
- **The installer sets PATH for zsh, bash and fish**, without asking (#174).

## Changed

- **`ia tasks submit --wait`: a 429 while polling is rate limiting, not an
  error** (#168). The wait sleeps the `Retry-After` and polls again. In
  `ia-core`, a 429 from `get_tasks`, `list_tasks`, `get_task_log` and
  `get_rate_limit` is now `IaError::RateLimited`, not `Http { status: 429 }`;
  with `--json` the error code is `rate_limited` instead of `http_error`.
- **Spreadsheet and JSONL reader** (#172; `ia upload`, `ia metadata`,
  `ia tasks submit`, `ia verify`):
  - JSONL numbers and booleans are sent as text as written (`1.50` stays
    `1.50`; 0.27.0 sent `1.5`).
  - JSONL objects, arrays holding anything but strings, and broken strings
    are refused, with the line number. `null` is no value.
  - A JSONL line with no identifier refuses the file. The `identifier` key
    matches in any case.
  - JSONL strings are trimmed.
  - A spreadsheet with the same header twice is refused (every command that
    reads one, `ia collection create` included).
- **`ia metadata export`, resumed:** an unreadable earlier file stops the run
  and is left as it is, so earlier rows are no longer overwritten; header
  case is kept across resumes.
- `ia-core` gains `spreadsheet::read_exported_spreadsheet`. The XLSX/ODS
  missing-`identifier` error and the JSONL parse error are now
  `IaError::InvalidArgument` (were `Config`).
