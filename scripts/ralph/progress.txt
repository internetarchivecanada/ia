## Codebase Patterns

- **Workspace structure:** ia-core (library) + ia-cli (binary). Core logic always goes in ia-core for reuse by CLI + future GUI.
- **Error handling:** ia-core uses `thiserror` with `IaError` enum in `error.rs`. CLI uses `anyhow`. Core functions return `ia_core::Result<T>`.
- **HTTP client:** `IaClient` wraps `reqwest-middleware::ClientWithMiddleware`. Access inner client via `client.http()`. Note: `reqwest-middleware` doesn't expose `.json()` — use `.header("content-type", ...).body(serde_json::to_vec(...))` instead.
- **Config:** `IaConfig` loaded from ia.ini (INI format). S3 creds already in `config.s3_access` / `config.s3_secret`. Config loading in `config.rs`.
- **wiremock test helper:** Every test module that does HTTP uses this pattern:
  ```rust
  fn mock_config(server_uri: &str) -> crate::config::IaConfig {
      let mut config = crate::config::IaConfig::default();
      let host = server_uri.strip_prefix("http://").or_else(|| server_uri.strip_prefix("https://")).unwrap_or(server_uri);
      config.general.host = host.to_string();
      config.general.secure = false;
      config
  }
  ```
  For write tests, also set `config.s3_access` and `config.s3_secret`.
- **Serde quirks:** IA returns file size/mtime as strings. `StringOrVec` handles single string vs array. `MetadataFields` has typed common fields + `#[serde(flatten)] extra: HashMap<String, Value>`.
- **CLI pattern:** clap 4 derive. `MetadataArgs` struct with `#[derive(clap::Args)]`. Global flags reserved: `-c, -l, -d, -i, -H, -j, -q`.
- **Joblog:** JSONL append-only. `JoblogEntry::new(op, item, file).ok(bytes, elapsed_ms)` or `.error(msg, retries)` or `.skipped()`. Writer is `Arc<Mutex<File>>`.
- **Batch identifiers:** `collect_identifiers()` merges positional args, --itemlist file, --search query (async stream), stdin. See download.rs for reference pattern.
- **TDD:** Write failing test first, verify it fails, implement minimal code, verify it passes, commit.
- **Rust version:** 1.85. Pin comfy-table to 7.1.x, wiremock to 0.6.2 (later versions need let chains).
- **Commit style:** `feat: description`, `test: description`, `refactor: description`, `chore: description`, `docs: description`.
- **GitHub:** ALWAYS `gh auth switch --user jjjake` before any gh/git push command.
